# 1.0 验证范围

正式版剧场适配后，完整 Node 回归共 **907 项：906 通过、0 失败、1 跳过**。首发整理前基线为 904 项：903 通过、0 失败、1 跳过；跳过项是需要本机旧版引擎基线的性能对比，不影响普通回归。Claude CLI 独立复跑得到相同结果。公开源码改为合成 fixture 后另有发布前复测，记录见 `reports/public-validation.json`。

另用本机未修改的 DSH 气泡解析器对开场做契约复现：旧插件截断小茂一行，修复后大木与小茂的气泡行都不再被文本标记拆开。API 7 原生 BGM 的空曲目／静音归属、iframe 启动前限制、手势重启保护及攻击音效另有回归。没有修改用户真实聊天。

- 自然语言选择、移动、指定野怪、否定／假设与历史语境、普通 NPC 与命名 NPC 邀约、舞台／正文两个入口去重。
- 单打／双打、道具与特性、有限 NPC 用药、捕捉／逃跑、难度、AI 超时与非法回答回退。
- 真实击倒快照经验／EV、学习装置、交换经验、成长／学招／进化队列、邮件、放生、电脑管理。
- 城市设施、导师楼层、采购证据、委托里程碑、剧情分支与工具奖励。
- 工坊参数保存／读回一致、保护动画定时器、只读面板、JSON 延迟生成与图鉴缓存。
- 独立 Edge 浏览器实际开战、一次出招、刷新恢复、像素图解码；390 px 窄屏无横向溢出，页面无 JS 异常。截图在 `docs/images/`。
- 原生归档解析、插件临时解包导入、三个媒体包的原生资源存储导入及所有资源引用核对；在临时目录运行，未覆盖玩家安装。

## 如何复测

```sh
python scripts/fetch_assets.py
npm test
python scripts/check_repository.py
python scripts/build_card.py
```

测试隔离存档；不要把真实玩家对话复制成 fixture。CI 在两个操作系统运行同一套源码测试。检查器验证媒体引用、源码路径、打包约束及文档图片；构建报告逐项记录包内文件长度和 SHA256。

## 不能据此保证的内容

没有逐一完成人工长时间通关、所有真实旧局升级、所有硬件帧率与音乐听感测试。Node 已加载文件行覆盖率 96.99% 是当时特定测试运行的统计，不代表整个前端、全部资源或所有路径被证明正确，也不作为「零 Bug」保证。可选模型对手和 AI 剧情的耗时受外部服务影响。

原作地图脚本、全部隐藏物可达路径、七之岛与联机功能的限制见 README。首次发现的遗漏请提供最小复现，继续用回归测试固定。
