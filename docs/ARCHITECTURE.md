# 代码与状态边界

## 一次操作

玩家输入／舞台按钮 → 宿主回合与正文版本检查 → 识别合法行动 → 纯规则变更或战斗事件 → 校验 MVU → 原生接口提交 → 读取确认 → 渲染。

唯一持久状态是本局 `stat_data.宝可梦`。战斗模拟器持久快照与操作序号用于恢复，不能另算一份背包或结果。模型叙事和可选模型对手均不持有数值写入权；模型对手必须从合法候选中选择并支持超时回退。

## 模块

| 位置 | 责任 |
| --- | --- |
| `index.mjs` / `client.js` | 原生插件接口、任务和舞台挂载、回合写保护、资源根路径 |
| `settlement-provider.cjs` / `mvu.cjs` | 结算、默认值／迁移、世界规则与状态落盘 |
| `engine.cjs` / `vendor/showdown` | 第三世代战斗模拟、真实事件、快照与规则适配 |
| `story-runtime.cjs` / `story-intents.cjs` / `story-*.cjs` | 自然语言行动、邀约与消费、剧情状态及交谈 |
| `party.cjs` / `growth-mechanics.cjs` | 管理、成长、进化和学招 |
| `npc-quests.cjs` / `quest-gadgets.cjs` / `classic-services.cjs` | 委托证据、永久工具、城市设施 |
| `public/` | 原生嵌入页、战斗菜单、镜头、特效与资源清单 |
| `server.cjs` | 本地隔离预览，不代替 DSH 宿主 |

## 性能约束

只在真正需要时生成完整变量 JSON；目录展示使用有效性明确的缓存。状态提交保留正文版本和操作回执，避免无效重算；缓存不能跨越分支或把旧战斗写回新正文。隐藏页面暂停演出，特效纹理缓存及同时效果有上限。不要用删除校验、幂等与恢复保护换速度。

## 源码与发行卡

Git 提交代码、规则、测试、文档与少量截图。媒体通过首发 Release 的哈希固定；开发时解到被忽略的资源目录。打包时插件只包含代码／数据，图片与声音放在 `dsh.json` 声明的独立包中。`scripts/build_card.py` 生成标准 ZIP 结构的原生 `.dshcard`，不会安装插件或操作玩家目录。

## 宿主兼容

发行清单要求 API 4，并探测 `mvuSettlementProvider` 能力。对白气泡与舞台基底交给宿主控制。源码测试可模拟接口契约，但不能替代宿主真实导入与升级验收。维护接口时应以本体公开契约为准，不为一次宿主更新添加永久私有补丁。
