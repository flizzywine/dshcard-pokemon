# 关都逐格地图

`tile-world.cjs` 负责移动、碰撞和已接入的地图机关。`ensure(world)` 为旧存档补上 `world.tileWorld`；`validate(world)` 检查位置；`view(world)` 返回当前地图、碰撞、事件和版本号；`apply(world, action, payload, options)` 在副本上执行一步，返回 `{world, result}`。传入的 `expectedRevision` 与存档版本不一致时，操作会被拒绝。地图按钮会附上该版本号。

地图格与事件坐标来自固定版本 `pret/pokefirered`（`ce6406d8c2eaf46d543c8a2606de0c3cb1951982`）。数据包导入了 423 个关都与七之岛地图的布局、碰撞、事件和图块素材；这表示地图数据覆盖面，不代表每个原作脚本和谜题都已实现。

## 已有规则与回归覆盖

- 地图按源碰撞信息移动，普通门、楼梯和传送格按源地图中的目标 warp 序号换图。金黄道馆的 Sabrina 传送格有专门的目标序号回归测试。
- 枯叶道馆垃圾桶谜题生成两个相邻垃圾桶；查找对象必须在玩家一格之内。错误的第二个选择会重置谜题。
- 海沫洞窟支持力量术推动巨石落洞、对应楼层出现可推动的巨石，以及源图块 `0x50–0x53` 标出的水流推动。冠军之路巨石需要可用的力量术，并遵守目标格碰撞。
- 火箭队基地按源旋转格方向移动；电梯需要升降机钥匙，并能选择已接入楼层。西尔佛公司门卡门和宝可梦屋开关会更新地图碰撞。
- 隐藏道具需持有探宝器才会显示或拾取；`underfoot` 道具要求站在原坐标。若原作对象（例如尚未处理的卡比兽）仍占据该格，拾取会被阻止。物品一次性写入共享背包和源 flag。
- 页面提供中文方向、互动、推石、开门和返回区域按钮，键盘也可作为补充操作。返回按钮关闭 app 中已有的地图折叠面板。图块素材解码缓存最多保留 16 个 atlas；每步更新后会恢复当前操作按钮的焦点。

对应行为测试位于 `test/tile-world.test.cjs` 和 `test/tile-world-ui.test.cjs`；真实页面素材装载与控件接线另由 `test/app-live-world-features.test.cjs` 覆盖。

## 当前未执行的原作脚本

地图事件表保留了大量原作对象、训练家、告示和脚本名称，但未接入专用规则的交互只返回事件 intent，不会运行原作脚本。当前实现不应被描述为完整的 FRLG 地图谜题模拟器。仍未完整执行的部分包括：

- 各处训练家视线触发、对话、奖励和剧情 flag 脚本，以及大多数 NPC 事件。例如 `Route12_EventScript_Snorlax`、`PokemonTower_7F_EventScript_MrFuji` 和 `ViridianCity_Gym_EventScript_Giovanni` 目前不会由逐格界面执行；隐藏物的阻挡 flag 需要由已有剧情系统或存档设置。
- 火箭队基地内的剧情对白、训练家事件、密码线索和剧情 flag。例如 `RocketHideout_B2F_EventScript_Grunt` 不会启动训练家战斗；当前只接入旋转格、`RocketHideout_Elevator_EventScript_FloorSelect` 电梯和可识别的物品球。
- Sabrina 入口 warp 序号已按源地图回归覆盖，但 `SaffronCity_Gym_EventScript_Sabrina` 的对话、战斗与徽章剧情并未执行。金黄道馆以外依赖剧情脚本的传送/机关也未完整接入。
- 狩猎地带的入场计费、步数、投球和区域切换等脚本流程。
- 狩猎地带的入场计费、步数、投球和区域切换等脚本流程。
- 一处无相邻可走格、又非站立拾取的源隐藏物无法通过当前逐格移动触达。若后续更改地图适配，需单独证明其可达性。

导入器保留源事件与脚本 ID，便于逐项实现和测试；不认识的脚本会留作 intent，不会被伪装成已经执行。
