# FRLG battle reward settlement source

The reward class factors and prize formula are taken from `pret/pokefirered` commit `ce6406d8c2eaf46d543c8a2606de0c3cb1951982`. `src/battle_main.c` defines all 104 `gTrainerMoneyTable` entries (lines 439–547; SHA-256 `c290d325761d68c059f02dc21cc6178d4bbefa0d06ffddc8879341c090d37928`). `src/battle_script_commands.c` defines `Cmd_getmoneyreward` (lines 5030–5088; SHA-256 `3b7341db8cd58c54fb0b54b47e6eef89c5c05e8a60ab4e9b45bdc907845c19b3`). Normal trainer prize uses `4 × final party Pokémon level × money multiplier × (double battle ? 2 : 1) × trainer class value`; wild battles have no trainer prize. The MVU now chooses the last party member's level, not the highest level.

Current local encounter mappings: `gym` uses Leader (25); League stages 0–3 use Elite Four (25), stage 4 uses Champion (25); the first Pallet Town fight with 小茂 uses Rival Early (4); road trainer labels 捕虫少年, 登山男, 短裤小子 and 迷你裙 map to Bug Catcher (3), Hiker (9), Youngster (4) and Lass (4). The authored Route 22 rival rematch and Silph rival trial use Rival Late (9) as approximate mappings. The Rocket bridge uses Team Rocket (8); the authored Celadon rocket officer also uses Team Rocket (8) approximately. The original-content Indigo tournament uses Pokémon Trainer (15) approximately. Unmapped trainer classes return no prize instead of fabricating a class value.

`moneyMultiplier` and `doubleBattle` are explicit options on `frlg-rewards.cjs`; Amulet Coin now activates the persisted multiplier when a living holder enters; double battles remain unmodeled. No item effect is invented. Whiteout money loss is not implemented because the player party / whiteout conditions are not represented accurately enough to safely apply `ComputeWhiteOutMoneyLoss`.

EXP and EVs from each defeated enemy are settled once when any battle outcome ends, using existing per-enemy participants and living-at-defeat snapshots. This fixes earned EXP being lost if the player's last Pokémon faints after a KO. Level growth remains deferred until postbattle; this does not recreate FRLG's midbattle move learning or immediate battle-stat synchronization. A Pokémon that fainted during battle remains at 0 HP after deferred max-HP growth.

Sources: [pinned `battle_main.c`](https://github.com/pret/pokefirered/blob/ce6406d8c2eaf46d543c8a2606de0c3cb1951982/src/battle_main.c), [pinned `battle_script_commands.c`](https://github.com/pret/pokefirered/blob/ce6406d8c2eaf46d543c8a2606de0c3cb1951982/src/battle_script_commands.c).
