# Generated trainer portrait assets (0.9.3)

Created with the built-in image_gen tool as separate image requests. All five final images are 1024×1536 RGBA PNGs with transparent alpha channels. Their SHA-256 hashes, alpha bounds, portrait traits, generation prompts and source paths are stored in npc-portraits.json.

The requested characters are: original-series Ash (age 10), adult male ace trainer, adult female travel trainer, teenage girl backpacker, and middle-aged female breeder. The four anonymous roles are registered as fallback-only portraits. Ash is a named character and is separately declared in trainers.json with his previous portrait retained as fallback.
